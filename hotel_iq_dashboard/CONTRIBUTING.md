# Contributing to Hotel IQ

Thanks for your interest in improving this project.

## How to contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Commit your changes with a clear message
5. Push to your branch
6. Open a Pull Request

## Reporting issues

If you find a bug or have a feature request, please open an issue describing:

- What you expected to happen
- What actually happened
- Steps to reproduce (if it's a bug)

## Code style

- Keep functions in `utils.py` focused on data loading and metric computation
- Keep UI/layout code in `app.py`
- Favor clear variable names over comments where possible
